# ICNDEMAC-2027 submissions

Two IEEE conference papers for the **1st International Conference on
Nano-Devices, Emerging Materials for Advanced Computing (IEEE ICNDEMAC-2027)**,
Feb 26–27, 2027 (IEEE Conference ID #71263). Both papers are built on the
open-source **DDM.SPC** solver
(<https://github.com/eghamit/Schrodinger>) — a 2-D finite-element
drift-diffusion semiconductor device solver with a self-consistent
Schrödinger–Poisson quantum correction, heterojunctions, MOS/Schottky contacts,
Fermi–Dirac statistics and LED optical output.

| Folder | Track | Title |
|--------|-------|-------|
| [`track2-quantum-nanoelectronics/`](track2-quantum-nanoelectronics) | **Track 2 – Nano-Electronics** | A Self-Consistent Finite-Element Schrödinger–Poisson Drift-Diffusion Solver for Quantum-Confinement Effects in Ultra-Thin-Body Nanoscale Devices |
| [`track1-nanophotonics/`](track1-nanophotonics) | **Track 1 – Nano-Materials for Advanced Devices** | Finite-Element Drift-Diffusion Modelling of Direct-Gap III–V Light-Emitting Diodes: Wavelength Tuning and Double-Heterostructure Efficiency in Nano-Photonic Emitters |

All numbers and figures in both papers were generated by running the solver;
each folder contains a `reproduce_results.py` that regenerates its figures and a
`results.json` recording the harvested values.

## Building the PDFs

Each paper is a standalone IEEEtran (`conference`) document. From a paper folder:

```bash
pdflatex main.tex && pdflatex main.tex     # run twice for cross-references
```

or upload the folder to Overleaf (IEEEtran is built in). A pre-built `main.pdf` (6 pages)
is included in each folder.

## Reproducing the results

The scripts need the solver installed:

```bash
git clone https://github.com/eghamit/Schrodinger
cd Schrodinger && pip install -e '.[all]'
python /path/to/<paper-folder>/reproduce_results.py   # writes figures/ + results.json
```

## Before submitting

- Fill in the author block in each `main.tex` (names, affiliation, emails).
- Confirm the paper meets the IEEE conference template / page-limit rules and
  submit via <https://cmt3.research.microsoft.com/ICNDEMAC2027>.
- Full-paper submission deadline (extended): **20 September 2026**.
